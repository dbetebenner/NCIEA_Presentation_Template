# Examples

Worked decks built from this template live in their own repos/folders so the
template stays lean. A full real-world example — an AI-supported-workflows
brown-bag talk exercising most components (callout boxes, columns, figures,
speaker notes) — was built in `NCIEA_2026_Retreat/AI_Workflows_BrownBag/`.

Drop a rendered `example.html` here if you want a committed reference build.
